### 👨‍💻 About me

Developer focused on solving real problems with clean, tested software and AI where it actually helps.

- 🧠 **AI & LLMs:** agents with tool use, RAG with citations, structured extraction, evals and MCP servers that plug data into AI assistants.
- 📊 **Data:** ETL pipelines, time series with pandas, dashboards, and machine learning with scikit-learn.
- 🤖 **Automation:** Playwright bots, scheduled GitHub Actions workflows and document processing.
- 🚀 **Product:** web apps and APIs in TypeScript and Python, from requirements to deploy, with CI and tests.

🇧🇷 Based in Brazil · Most of my projects use Brazilian public data and are documented in Portuguese.

### 🛠️ How I work

- **Tests and CI on every project:** unit, integration and end-to-end (pytest, Vitest, Playwright).
- **Measure before claiming:** evals for search and LLM output, cost tracking for API calls.
- **AI-assisted development:** I build with Claude Code, and my repos ship with `CLAUDE.md`, hooks, skills and review agents so the workflow is reproducible.
- **Each project has a study guide** (`docs/GUIA-DE-ESTUDO.md`) explaining the concepts behind it.
